# Trip Settlement

Trip settlement app for Uddhava Logistics: trip entry, approval tracking, diesel debit, driver and vehicle master, and a vehicle/driver dashboard.

- Live app: https://aravindanr-create.github.io/trip-settlement/
- Data: Supabase project `Trip_Settlement` (tables prefixed `ts_`). Sign-in required.

The key in `index.html` is a Supabase publishable key. It is safe to publish: the database refuses every request that is not from a signed-in user.
